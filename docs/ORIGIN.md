# Origin record

This file records where Living Racetrack came from and what is original to it. Keep it in the repository: together with the dated commit history, it is your public record of authorship.

**Author:** Arun Pun ([@imarun-pun](https://github.com/imarun-pun))

**First working software:** Pit Wall v1, 11 October 2026
**This version:** Pit Wall v0.2

## The idea in one sentence

A premium connected display that brings a racetrack to life on a wall: it chooses what to show by itself (a live session, a replayed race, or a calm ambient circuit), so the track is always alive, not just on race weekends.

## What is original to this project

- The product concept: an always-on racetrack display that switches between live, replay, ambient and event modes on its own, sold in Mini, Medium and Large hardware editions.
- The name *Living Racetrack* and the *Pit Wall* display software (trademark searches still to be done before commercial use).
- All source code in this repository.
- The visual design: the glowing-track look, timing tower, pit cam, garage break and ambient layout.
- The four original circuits: Marina Lights, Kestrel Park, Highland Loop and Dune Crescent.
- The ten fictional teams, their liveries, the twenty driver codes and the single-seater car drawing.
- The race simulation: speed profiles from track curvature, traffic, pit strategy, weather and incidents.

## What is not claimed

- Real-world circuit layouts. They are geography, traced by an open dataset (see `THIRD_PARTY.md`), and are named here by location only.
- General motorsport knowledge: flags, safety cars, tyre compounds and pit stops are part of the sport, not of this project.
- Other connected wall art, LED track maps and live-timing apps exist. Living Racetrack does not copy their designs or code. What sets it apart is the combination: an automatic mode engine, a simulation that is honest about being a simulation, and a product built as home decor first.

## How to strengthen the record

1. Push this repository to GitHub with your real name or a clearly linked account. Every commit is timestamped.
2. Tag releases (`git tag v0.2.0 && git push --tags`) so each version has a fixed date.
3. Keep the original concept brief in `docs/` as well.
4. Before selling anything, run trademark searches for *Living Racetrack* and *Pit Wall* in your markets (USPTO TESS in the US) and consider filing for the one you keep.
5. For the physical enclosure, ask an IP attorney whether a design patent is worth filing before you show prototypes publicly.

An idea on its own cannot be owned. The code, the designs, the brand and a public, dated record of building it first can be, and this repository is that record.
